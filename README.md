# Sujan Nisha Wedding Stories

Create a luxurious Hindu wedding photo gallery website inspired by my uploaded reference image. Use a rich maroon, deep red, ivory, and antique gold color palette with elegant traditional details.

Build a beautiful masonry-style gallery with categories for Couple, Family, Ceremony, Friends, and Celebrations.

Most importantly: When users click a photograph, open it in an immersive fullscreen viewer with cinematic zoom-in animations, smooth transitions, next/previous navigation, keyboard controls, and swipe support on mobile.

Use Framer Motion for elegant animations, subtle hover effects, and smooth gallery filtering.

Make the website fully responsive, visually stunning, and premium. Focus on photography presentation rather than unnecessary website sections.
